## ランチェスターの法則

### 第一法則（一騎打ち・局地戦）

```
戦闘力 = 武器性能 × 兵力数
```

数の差が**線形**にしか効かない。5対3なら、質で約1.7倍の差をつければ互角に持ち込める。

### 第二法則（確率戦・広域戦）

```
戦闘力 = 武器性能 × 兵力数²
```

数の差が**二乗**で効く。5対3なら 25対9 で約2.8倍の開き。質で埋めようとすると2.8倍の性能差が必要になり、現実にはまず不可能。

### ここから導かれる結論

**弱者は第二法則が働く戦場に絶対に立ってはいけない。**

第二法則が働くのは、遠隔・広域・不特定多数を相手にする戦い方 — マス広告、価格競争、全国展開、総合品揃え、汎用商品。ここで大手と正面から当たると、数の差が二乗で効いて必ず負ける。

弱者が生き残れるのは第一法則が働く場所 — 特定地域、特定用途、特定顧客層、直接対面、深い関係性。

これは精神論ではなく、**どの土俵に立つかで数の不利の効き方が変わる**という構造の話。弱者の戦略とは要するに「第一法則の戦場を選び続けること」に尽きる。

## 弱者の戦略（五原則）

1. **局地戦** — 戦う範囲を狭く限定する。地域、業種、用途、顧客層のいずれかで切る
2. **一騎打ち戦** — 競合の少ない（理想は1対1になる）領域を選ぶ。多数が入り乱れる市場は確率戦になり第二法則が働く
3. **接近戦** — 顧客との距離を詰める。直販、対面、密なやり取り。大手が構造的に真似しにくい
4. **一点集中** — 限定した1点に全リソースを投下する。**分散は弱者にとって敗北と同義**
5. **陽動戦** — 強者の注意が向かない場所・規模・タイミングで動き、反撃を遅らせる。虚偽で欺くことではなく、**相手の関心の外側を選ぶ**こと（偽情報の扱いは `invincibility.md`）

### 五原則で選んだ戦場で何を磨くか

戦闘力は「武器性能 × 兵力数」なので、局地戦に持ち込んだ弱者が上げられるレバーは2つある。

- **武器性能** — 質・差別化・知財・専門性。第一法則の戦場では兵力差が線形にしか効かないので、性能差で埋められる範囲が広い
- **実質兵力** — 絶対量ではなく資本の回転で稼ぐ（`weak-position.md` の「資本回転率という兵力増強」）

どちらか一方ではなく、両方を上げるのが弱者の基本形。

### 「1位を取れる最小単位」を探す

弱者の診断で最も効くのがこの問い。

> **どこまで市場を切れば、そこで1位になれますか**

「県内で」で無理なら「市内で」、それも無理なら「この用途に限れば」「この業種の顧客に限れば」。1位が取れる単位が見つかるまで切り続ける。1位になれば、その狭い領域では相対的に強者になり、口コミ・紹介・情報が集まる好循環が始まる。

**2位以下に価値はほとんど無い**という前提で考えると判断が速くなる。

### 弱者が絶対にやってはいけないこと

- 価格競争を仕掛ける（体力勝負は資源量で決まる）
- 品揃えで対抗する（在庫と管理コストで潰れる）
- マス広告で認知を取りに行く（露出量の勝負は二乗で効く）
- 大手の主戦場に正面から参入する

## 強者の戦略と同質化

強者の基本は**広域戦・確率戦・総合戦**。数の優位が二乗で効く土俵に持ち込み、面で制圧する。

### 同質化（ミート戦略）

強者にとって最も効率的な打ち手。弱者が差別化で当てたら、それを模倣して自社の販売力・ブランド・チャネルに乗せる。差別化の価値が消え、残るのは資源量の勝負になり、強者が勝つ。

**弱者側の診断では、この反撃を必ず想定に入れる。** 「成功したら真似される」ではなく「**成功したら必ず真似される**」を前提に、模倣に時間がかかる要素へ賭けているかを検証する。すぐ模倣される要素は優位の源泉にはならないが、模倣されるまでの遅延は蓄積の猶予時間として使える（`weak-position.md` の「速度と蓄積をどう両立させるか」）。

### 強者側の落とし穴

強者を診断する場合、以下が典型的な弱点になる。

- **既存事業とのカニバリズム** — 新しい勝ち筋が既存の収益を食うため動けない（イノベーターのジレンマ）
- **意思決定の遅さ** — 規模ゆえの階層と調整コスト
- **全方位対応による焦点の喪失** — 面を取ろうとして、どの領域でも中途半端になる
- **小さすぎる市場を無視する** — 弱者に足がかりを与える

強者の処方は「弱者の芽を早期に潰す仕組み」と「自社の既存事業を自ら食う覚悟」に集約されることが多い。

## 直接戦略と間接戦略

### 直接戦略（クラウゼヴィッツ型）

敵の主戦力を撃滅し、決戦で決着をつける。**資源で優る側の選択肢**。目的が明確で、力の集中が可能で、短期決着が見込める場合に有効。

戦争の本質を「他の手段をもってする政治の継続」と捉える視点は経営でも有効で、**戦略は常に上位の目的に従属する**ことを思い出させてくれる。競争に勝つこと自体が目的化していないかの点検に使う。

### 間接戦略（孫子・ボーフル型）

正面衝突を避け、相手の弱点・意思・基盤を突く。情報、時間、心理、経済的圧力、第三者の動員を組み合わせる。**資源で劣る側の選択肢**であり、現代の競争環境では非対称な手段が取りやすいため有効性が高い。

- **相手が守りにくい場所を選ぶ**（既存事業とカニバる領域、収益性が低くて手を出しにくい領域）
- **相手が反応するまでの時間を稼ぐ**（気づかれない規模で足場を固める）
- **戦わずに済む構造を作る**（補完関係、提携、土俵の移動）

### 選択の基準

| 状況 | 型 |
|---|---|
| 資源で優る／短期決着可能／目的が単純 | 直接 |
| 資源で劣る／長期戦／相手の弱点が明確 | 間接 |
| 相手の意思決定が遅い | 間接（時間を武器にする） |
| 相手の内部に対立がある | 間接（そこを突く） |

## 主導権をどう握るか

対等な力関係の場合、勝敗は主導権の所在で決まる。主導権とは「相手を自分の設定した土俵で反応させ続ける状態」。

**主導権を握る手段:**

- **土俵を先に定義する** — 競争の評価軸を自社有利に設定し、業界の共通言語にしてしまう
- **相手の意思決定サイクルより速く動く** — 相手が対応を決める頃には次に移っている（OODAループの回転速度）
- **不可逆なコミットメント** — 後戻りできない投資を公然と行い、「本気である」ことを相手に認識させる（詳細は `invincibility.md` の「正当なシグナリング」）
- **相手に選択を強いる** — どちらを選んでも自社が得をする状況を作る

**主導権を失っている兆候:** 打ち手が全て競合への対応になっている、値下げに追随している、相手の新製品への反応で予算が消えている。この状態を診断で見つけたら、**まず主導権の回復を最優先の処方にする**。個別の施策改善では抜け出せない。
